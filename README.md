# rapidjson-learning
rapidjson-learning is a personal project to practice using [rapidjson](https://github.com/Tencent/rapidjson) (at commit 24b5e7a8)

# Building the project
## On Windows, Visual Studio Build Tools
1. Download the Windows release in [Premake](https://github.com/premake/premake-core) (Any release)
2. Run `premake5.exe` in command with these arguments: `premake5 vs2022`
3. Open the solution is in folder `generated/vs2022/rapidjson-learning.sln`
4. Build and Debug the solution with [Visual Studio](https://visualstudio.microsoft.com/downloads/) (with preferably MSVC v143 - VS 2022 C++ x64/x86 build tools)
